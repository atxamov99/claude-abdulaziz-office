# Штаб-квартира · Claude HQ Office

Telegram-бот для нескольких долгоживущих Claude Code воркеров и локальный визуальный офис: комнаты, инструменты, субагенты, история задач, очередь и статистика токенов.

**Статус: экспериментальный macOS-first проект.** Это обезличенная версия персональной системы, не готовый многопользовательский облачный сервис. Не официальный продукт Anthropic.

## Что внутри

- `hq/` — Telegram-мост, локальный HTTP API, MCP-инструменты и учёт поручений.
- `office/` — приложение React + PixiJS + Tauri, адаптация [Claude Code Park](https://github.com/t-soda/claude-code-park), MIT, автор t-soda.
- Долгоживущие процессы `claude -p` со stream-json: один воркер на проект, последовательная обработка ходов, возобновление сессий.
- Диспетчер, журнал действий, обзор субагентов по событиям Agent/Task, фоновые события CLI, usage по поручению с дедупликацией ID сообщений.

## Установка HQ

Нужны macOS, Python 3.11+, установленный и авторизованный Claude Code. Для Office — Node.js 22+, npm, Rust и Xcode Command Line Tools. Использование Claude требует собственного доступа; проект не предоставляет подписку или токены.

```sh
git clone https://github.com/abubakirilhomov/shtab-kvartira.git
cd shtab-kvartira
# Не выполняйте копирование поверх существующего HQ.
test ! -e "$HOME/claude-hq" && cp -R hq "$HOME/claude-hq"
cd "$HOME/claude-hq"
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python setup_config.py
```

Заполните локальный `.env`: Telegram API ID/hash, токен своего бота и **свой числовой TG_OWNER_IDS**. Получайте их через официальные инструменты Telegram. Не отправляйте секреты в issues или чаты. Без владельца бот не запускается.

Добавьте свои проекты в `~/claude-hq/projects.json`, например:

```json
{"projects":{"hq":"/absolute/path/to/claude-hq","my-app":"/absolute/path/to/my-app"},"topics":{}}
```

```sh
.venv/bin/python bot.py
```

После запуска напишите боту `/help`. Автозапуск не устанавливается автоматически. Клиентские агенты отключены по умолчанию (`clients.py: SPECS = {}`); их включение и разграничение доступа требуют отдельной настройки.

## Разрешения Claude

По умолчанию `HQ_PERMISSION_MODE=dontAsk`: неразрешённые операции отклоняются, а не запрашивают подтверждение в невидимом терминале. Разрешите необходимые инструменты в настройках конкретного проекта. Режим `bypassPermissions` допускается только осознанно в изолированной доверенной среде: он отключает проверки разрешений Claude. В публичной версии главный агент не получает автоматически доступ ко всему домашнему каталогу.

## Запуск Office

Из каталога этого репозитория:

```sh
cd office
npm ci
npm test
npm run tauri dev
# Сборка локального macOS-приложения:
npm run tauri build -- --bundles app
```

Office ожидает HQ на `127.0.0.1:8765` и его файлы в `~/claude-hq`. Пока эти пути не настраиваются через интерфейс. Готовых подписанных установщиков в первом выпуске нет.

## Проверки

```sh
cd ~/claude-hq
.venv/bin/python tests/test_office_telemetry.py
```

Тесты используют искусственный поток, не запускают Claude и не отправляют сообщения в Telegram. Frontend: `npm test`; Rust: `cargo test --manifest-path office/src-tauri/Cargo.toml --lib` из корня репозитория.

## Ограничения

- Точное соответствие usage поручению есть только для новых наблюдённых ходов. Отдельный расход субагентов не прибавляется к расходу родителя.
- Состояния субагентов восстанавливаются по журналам, не по проверке процессов. Внешние cron/launchd/скрипты автоматически не обнаруживаются.
- Телеметрию ходов пишет HQ и при закрытом Office; история снимков Office собирается только пока работает приложение.
- После перезапуска воркеры создаются по первому поручению; сохранённые ID сессий используются для resume.
- «Ход завершён» означает результат CLI, а не независимую проверку результата работы.
- Старый экран «Метрики Park» считает общую статистику иначе; для HQ используйте диспетчер и историю HQ.
- Интерфейс русифицирован частично. Поддержка Windows/Linux не проверена.
- Исправлена обработка `last: null`: отсутствие usage больше не должно ронять карточку воркера.
